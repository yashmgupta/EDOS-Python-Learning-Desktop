# EDOS Community Code of Conduct

## Our Goal

The EDOS community exists to improve educational technology for students, teachers, and beginner programmers.

We want participation to be respectful, constructive, inclusive, and focused on learning.

## Expected Behavior

Participants are expected to:

- communicate respectfully;
- assume good intent while still discussing technical disagreements clearly;
- give feedback about ideas and work rather than attacking individuals;
- welcome beginners and educators who may not have professional software-development experience;
- avoid humiliating or dismissive responses to basic questions;
- respect cultural, linguistic, and educational differences;
- protect student privacy;
- credit the work of others appropriately;
- disclose important conflicts of interest when relevant; and
- help maintain a safe educational environment.

## Unacceptable Behavior

The following behavior is not acceptable in project spaces:

- harassment, threats, intimidation, or personal attacks;
- discriminatory or demeaning language;
- sexual harassment or unwanted sexual attention;
- publishing another person's private information without permission;
- deliberately disrupting project discussions;
- plagiarism or intentional misrepresentation of authorship;
- knowingly uploading malicious code or harmful content;
- attempts to exploit students or collect sensitive student information improperly; or
- repeated behavior that project maintainers have asked a participant to stop.

## Educational Safety

Because EDOS may be used by young students, contributors should be especially careful with:

- links to external websites;
- uploaded datasets;
- examples involving personal information;
- network requests;
- browser storage;
- executable code samples; and
- third-party content.

Do not contribute material that would be inappropriate for a general educational environment.

## Enforcement

Project maintainers may edit, hide, close, or remove Issues, comments, pull requests, discussions, or other contributions that violate this Code of Conduct.

Depending on severity and repetition, maintainers may warn, temporarily restrict, or permanently block participation in official EDOS project spaces.

## Reporting a Problem

If a conduct problem can safely be discussed publicly, report it to the project maintainers through the repository.

If the matter includes sensitive personal information, harassment evidence, or a security concern, avoid posting those details publicly. Contact the project owner or use an appropriate private GitHub reporting mechanism where available.

## Scope

This Code of Conduct applies to official EDOS project spaces and to interactions where a participant is clearly representing the EDOS project.

## Attribution

This is an EDOS-specific community policy written for the project's educational context.
