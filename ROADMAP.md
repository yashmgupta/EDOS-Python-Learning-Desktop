# EDOS Roadmap

This roadmap describes possible development directions for **EDOS — Educational Desktop Operating Simulator**. It is not a guarantee of delivery dates.

## Vision

Make beginner Python education accessible from a browser with minimal setup, strong visual guidance, practical notebooks, and classroom-friendly learning materials.

---

## Phase 1 — Core Beginner Experience

### Python Learning

- [x] Python editor
- [x] Interactive terminal
- [x] Beginner-friendly error explanations
- [x] Guided lessons
- [x] English teaching deck
- [x] Thai teaching deck
- [x] Setup and installation learning material

### Notebook and Data Science

- [x] Jupyter-style notebook
- [x] Code cells
- [x] Markdown cells
- [x] Inline Matplotlib output
- [x] CSV examples
- [x] pandas-oriented beginner examples
- [x] Browser-side package-management workflow

### Content Library

- [x] Live GitHub `book/` folder
- [x] Nested folders
- [x] PDF viewing
- [x] CSV/TSV viewing
- [x] Notebook loading workflow
- [x] Text and image viewing

## Phase 6 — Teacher and Research Tools

Any analytics or research functionality should be privacy-first and opt-in.

Possible future areas:

- [ ] Anonymous local learning-progress export
- [ ] Teacher-created lesson packs
- [ ] Assignment templates
- [ ] Reproducible classroom research configuration
- [ ] Citation-ready lesson metadata
- [ ] Educator contribution portal/process

EDOS should avoid silently collecting student activity or code.
