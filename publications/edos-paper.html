Abstract

Practical Python instruction often requires learners and educators to configure development environments, manage dependencies, and distribute exercises before programming can begin. These requirements can complicate introductory teaching, especially in settings where installing local software is undesirable or restricted. This software design paper describes EDOS (Educational Desktop Operating Simulator), a browser-based educational desktop that brings several beginner-oriented programming activities into a single interface. Examination of the public repository identifies a Windows-inspired desktop, a Python editor and interactive terminal, Pyodide-based Python execution using WebAssembly, a Jupyter-style notebook interface, a browser-side package-management workflow, and a repository-backed learning library. The accompanying instructional materials include English and Thai teaching content, seven biology-oriented Jupyter notebooks, seven corresponding workshop PDF files, and three example CSV datasets. A biology data-analysis lesson illustrates sequence-length and GC-percentage calculations, species-level grouping, visualization, and simple treated-to-control gene-expression ratios using synthetic educational data. The available repository supports an architectural and content inventory, but does not establish educational effectiveness, cross-browser reliability, performance, or learner outcomes. EDOS is therefore presented as an implemented educational software artifact and a foundation for future controlled usability and learning-outcome evaluation.

Keywords: Python education; browser-based programming; Pyodide; WebAssembly; notebook learning; biological data science.

Publication status: This work is a publicly available preprint describing a software artifact. It should not be described as peer reviewed. The repository review did not include a controlled learner study or performance evaluation.
