# EDOS Live Learning Library

Files inside this `book/` directory are intended to appear in the EDOS **Books / Live Library** when the project is hosted publicly on GitHub Pages.

Use the subfolders by purpose:

```text
book/
├── python/       Python lessons and reference material
├── datasets/     Small classroom CSV/TSV datasets
├── notebooks/    Jupyter `.ipynb` teaching notebooks
└── workshops/    Workshop handouts, PDFs, and teaching packs
```

## Publishing rules

Only upload material that you have the right to publish.

Do not upload:

- private student data;
- copyrighted books or commercial PDFs without permission;
- passwords, keys, tokens, credentials, or confidential files;
- unnecessarily large datasets; or
- unsafe executable content intended to harm users.

Use clear filenames with lowercase words and hyphens where practical.

Example:

```text
python/python-loops-beginner.pdf
datasets/weather-week-01.csv
notebooks/dna-analysis-beginner.ipynb
workshops/python-introduction-workshop.pdf
```
