# Jupyter Notebooks

Place educational `.ipynb` files in this folder.

Notebook recommendations:

- start with a Markdown learning objective;
- keep code cells short;
- explain new concepts before using them;
- use relative paths to files in `book/datasets/` where practical;
- avoid unsupported native desktop dependencies;
- keep generated outputs reasonably small; and
- test the notebook in EDOS before publishing it for students.

Example filename:

```text
01-python-basics.ipynb
02-csv-with-pandas.ipynb
03-dna-nucleotide-analysis.ipynb
```
