# Classroom Datasets

Place small educational CSV or TSV datasets in this folder.

Good examples include:

- student-score examples using fictional names;
- weather observations;
- plant measurements;
- simple sales examples using fictional businesses;
- DNA/base-count examples;
- sports or science datasets with clear licensing.

Do **not** upload real private student records or sensitive personal data.

Include a short Markdown or text description when column meanings are not obvious.
